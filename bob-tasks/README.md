# bob-tasks/

Task and prompt definitions for Architecture Storyteller 2.0 & Ripple-Agent executed natively inside **IBM Bob IDE**.

## Execution Setup

1. **IBM Bob IDE v2.0+**: Open this repository directly inside IBM Bob IDE (`bobide`).
2. Run `/init` in the Bob chat panel to establish project context with `AGENTS.md`.
3. The custom Bob Skill `.bob/skills/polyglot-onboarding-and-refactor/SKILL.md` is discovered automatically by Bob's skill loader.
4. Bob executes with the persistent 40-coin budget funnel managed by `tools/storyteller-engine/coin_ledger.py`.

## Tasks in this folder

| File | Purpose |
|---|---|
| `ripple-analysis-prompt.md` | The actual multi-agent prompt executed in Bob IDE Agent mode for change analysis & downstream scanning. |
| `storyteller-ripple-status.json` | The real output manifest generated by Ripple-Agent showing AST diff, blast radius, contract warnings, and synthesized patch. |

## Budget Policy

40 Bob coins maximum budget enforced by `coin_ledger.py`. Local AST graph traversals and bug-fixing operations consume 0 coins.
